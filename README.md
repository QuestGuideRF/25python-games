## 🚀 Быстрый старт

### Установка

```bash
pip install freegames
```

### Запуск игры

```bash
python -m freegames.snake
```

### Список всех игр

```bash
python -m freegames list
```

### Копирование игры для редактирования

```bash
python -m freegames copy snake
python snake.py
```

## 🎮 Список игр

### 🎨 Графические игры (Turtle)

#### 🐍 Snake (Змейка)
**Классическая аркадная игра.** Используйте стрелки для управления змейкой и поедания зеленой еды. Каждый раз, когда еда съедена, змейка становится длиннее на один сегмент. Избегайте столкновения с собой или выхода за границы!

**Управление:** Стрелки ← ↑ → ↓

---

#### 👻 Pacman (Пакман)
**Классическая аркадная игра.** Используйте стрелки для навигации и поедания всей белой еды. Остерегайтесь красных призраков, которые бродят по лабиринту!

**Управление:** Стрелки ← ↑ → ↓

---

#### 🎯 Cannon (Пушка)
**Физика движения снарядов.** Кликните по экрану, чтобы выстрелить из пушки. Снаряд лопает синие шарики на своем пути. Лопните все шарики, прежде чем они пересекут экран!

**Управление:** Клик мыши

---

#### 🔴 Connect (Четыре в ряд)
**Игра "Connect 4".** Кликните по ряду, чтобы бросить диск. Первый игрок, который соединит четыре диска вертикально, горизонтально или по диагонали, побеждает!

**Управление:** Клик мыши

---

#### 🐦 Flappy (Флэппи Бёрд)
**Игра в стиле Flappy Bird.** Кликните по экрану, чтобы взмахнуть крыльями. Остерегайтесь черных ворон, пока летите по экрану!

**Управление:** Клик мыши

---

#### 🧩 Memory (Память)
**Головоломка с парами чисел.** Кликните по плитке, чтобы открыть число. Совместите два одинаковых числа, и плитки исчезнут, открывая изображение.

**Управление:** Клик мыши

---

#### 🏓 Pong (Понг)
**Классическая аркадная игра.** Используйте клавиатуру для перемещения ракетки вверх и вниз. Первый игрок, который пропустит мяч, проигрывает.

**Управление:**
- Игрок 1: `W` (вверх), `S` (вниз)
- Игрок 2: `I` (вверх), `K` (вниз)

---

#### 🎵 Simon Says (Саймон говорит)
**Классическая игра на память.** Кликните по экрану, чтобы начать. Смотрите на паттерн, а затем кликайте по плиткам в том же порядке. Каждый раз, когда вы правильно повторяете последовательность, паттерн становится на один шаг длиннее.

**Управление:** Клик мыши

---

#### ❌ Tic Tac Toe (Крестики-нолики)
**Классическая игра.** Кликните по экрану, чтобы поставить X или O. Соедините три в ряд и выиграйте!

**Управление:** Клик мыши

---

#### 🔢 Tiles (Пятнашки)
**Головоломка со скользящими числами.** Кликните по плитке, смежной с пустым квадратом, чтобы поменять их местами. Сможете ли вы расположить плитки от одного до пятнадцати слева направо и снизу вверх?

**Управление:** Клик мыши

---

#### 🏍️ Tron (Трон)
**Классическая аркадная игра.** Используйте клавиатуру для изменения направления вашего игрока Tron. Избегайте касания линии, нарисованной вашим противником.

**Управление:**
- Игрок 1: `A` (поворот влево), `D` (поворот вправо)
- Игрок 2: `J` (поворот влево), `L` (поворот вправо)

---

#### 🎨 Paint (Рисование)
**Рисование линий и фигур на экране.** Кликните, чтобы отметить начало фигуры, и кликните снова, чтобы отметить ее конец. Разные фигуры и цвета можно выбрать с помощью клавиатуры.

**Управление:**
- `L` - линия
- `S` - квадрат
- `C` - круг
- `R` - прямоугольник
- `T` - треугольник
- `K` - черный, `W` - белый, `G` - зеленый, `B` - синий, `R` - красный
- `U` - отменить

---

#### 🧬 Life (Жизнь)
**Игра Конвея "Жизнь".** Классическая клеточная автоматизация с нулевым количеством игроков, созданная в 1970 году Джоном Конвеем. Наблюдайте за эволюцией клеток по правилам игры!

**Управление:** Автоматическая симуляция

---

#### 🌀 Maze (Лабиринт)
**Перемещение с одной стороны на другую.** Вдохновлено "Вселенная в одной строке кода с 10 PRINT". Нажмите на экран, чтобы проследить путь с одной стороны на другую.

**Управление:** Клик мыши

---

#### 🎡 Fidget (Спиннер)
**Анимация спиннера.** Кликните по экрану, чтобы ускорить спиннер.

**Управление:** Пробел (ускорение)

---

#### 👁️ Illusion (Иллюзия)
**Оптическая иллюзия.** Визуальная демонстрация оптической иллюзии с квадратами и линиями.

**Управление:** Просмотр

---

#### ⌨️ Typing (Печать)
**Тренировка печати.** Практикуйтесь в печати, пока буквы падают вниз по экрану. Нажимайте соответствующие клавиши, чтобы удалить буквы!

**Управление:** Клавиатура (a-z)

---

#### 🐜 Ant (Муравей)
**Простая анимация муравья.** Демонстрация случайного движения муравья по экрану.

**Управление:** Автоматическая анимация

---

#### 💣 Avoid (Избегание)
**Классическая аркадная игра.** Используйте стрелки для управления игроком и избегания черных бомб, которые появляются со всех сторон экрана.

**Управление:** Стрелки ← ↑ → ↓

---

#### ⚽ Bounce (Отскок)
**Простая анимация мяча.** Демонстрация мяча, отскакивающего от стен экрана.

**Управление:** Автоматическая анимация

---

#### 💣 Minesweeper (Сапёр)
**Классическая игра "Сапёр".** Кликните по клеткам, чтобы открыть их. Избегайте бомб! Числа показывают, сколько бомб находится рядом.

**Управление:** Клик мыши

---

### 📝 Текстовые игры (Консоль)

#### 🔢 Bagels (Бейглз)
**Головоломка с числами.** Угадайте загаданное число из трех цифр. Вы получаете подсказки: "pico" (одна цифра правильная, но не на месте), "fermi" (одна цифра правильная и на месте), "bagels" (нет правильных цифр).

**Управление:** Ввод чисел в консоль

---

#### 🔐 Crypto (Шифрование)
**Инструмент для шифрования и дешифрования сообщений.** Используйте шифр Цезаря для шифрования и дешифрования текстовых сообщений.

**Управление:** Ввод команд в консоль (`encrypt`, `decrypt`, `decode`)

---

#### 🎲 Guess (Угадай число)
**Угадай число в диапазоне.** Компьютер загадывает число, а вы пытаетесь его угадать. Получайте подсказки "Выше" или "Ниже".

**Управление:** Ввод чисел в консоль

---

#### 📖 Mad Libs (Безумные истории)
**Игра создания смешных историй.** Заполните пропуски в шаблоне истории, вводя различные части речи (прилагательные, существительные, глаголы), и получите смешную историю!

**Управление:** Ввод слов в консоль

---

#### ✂️ Rock Paper Scissors (Камень, ножницы, бумага)
**Классическая игра "Камень, ножницы, бумага".** Выберите "r" для камня, "p" для бумаги или "s" для ножниц. Первый до 5 очков побеждает!

**Управление:** Ввод `r`, `p` или `s` в консоль

Каждая игра полностью независима от других и включает комментарии вместе со списком упражнений для работы со студентами. Творчество и гибкость важны. Нет правильного или неправильного способа реализовать новую функцию или поведение!

Игры отлично подходят для:
- Изучения основ программирования
- Понимания работы с графикой (Turtle)
- Изучения игровой логики
- Экспериментов с кодом
- Создания собственных модификаций
